# gmacks-school-project

Build from source:
1. Install go from go.dev
2. clone my repo
3. cd into my repo
4. run "go build ."

Run directly:
1. Install go from go.dev 
2. Install a C compiler like tdm-gcc (I suggest tdm-gcc)
3. clone my repo
4. cd into my repo
5. I suggest running "go install ." or "go get ." but if you run "go run ." it will do that stuff for you
6. run "go run ."

Using executable:
1. Run gmacks.exe
2. Your done!
